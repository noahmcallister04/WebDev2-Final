# College Student Budget Tracker

A full-stack web application that helps college students track income and expenses, manage monthly budgets by category, and view spending summaries on a dashboard.

| Andrew Danchus | Database (Mongoose models, seed data, aggregate queries) |

---

## Tech Stack

- **Frontend:** Angular 21 (standalone components, zoneless change detection)
- **Backend:** Node.js, Express 5
- **Database:** MongoDB Atlas via Mongoose
- **Styling:** Plain CSS

---

## Features

- Add, edit, and delete income/expense transactions
- Filter transactions by category, type, and month
- Set monthly budget limits per category
- Dashboard with income/expense summary and per-category progress bars
- Navigate the dashboard month-by-month with previous/next controls

---

## Getting Started

### Prerequisites

- Node.js v18+
- npm
- A MongoDB Atlas account (or local MongoDB instance)



### 1. Install and run the backend

```bash
cd backend
npm install
npm run dev
```

The API will be available at `http://localhost:3000`.

### 2. Install and run the frontend

Open a second terminal:

```bash
cd frontend/my-app
npm install
npm start
```

The app will be available at `http://localhost:4200`.
